# School Admission System (স্কুল ভর্তি সিস্টেম)

অনলাইন ভিত্তিক "আগে আবেদন করলে আগে পাবে" নীতিতে পরিচালিত স্কুল ভর্তি ও আসন ব্যবস্থাপনা সিস্টেম। এটি **Onnorokom Projukti Limited**-এর Assistant Software Engineer রিক্রুটমেন্টের টেক-হোম অ্যাসাইনমেন্ট হিসেবে তৈরি।

---

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Backend:** C# (.NET 8 Web API)
- **Database:** PostgreSQL 16
- **ORM:** Entity Framework Core 8 (Npgsql)
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS
- **Containerization:** Docker & Docker Compose
- **Testing:** xUnit, Microsoft.AspNetCore.Mvc.Testing

---

## 🚀 ডকার (Docker) দিয়ে অ্যাপ চালু করার ধাপ

আপনার কম্পিউটারে শুধু **Docker** এবং **Docker Compose** ইনস্টল থাকলেই চলবে। অন্য কোনো রানটাইম বা ডাটাবেস আলাদাভাবে ইনস্টল করতে হবে না।

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone <your-repo-url>
cd <repo-folder>
```

### ২. ডকার কম্পোজ দিয়ে সব সার্ভিস একসাথে চালু করুন
```bash
docker compose up --build
```
> এই একটি কমান্ডেই PostgreSQL ডাটাবেস, .NET 8 ব্যাকএন্ড এবং React ফ্রন্টএন্ড স্বয়ংক্রিয়ভাবে বিল্ড হয়ে রান করবে।

### ৩. অ্যাপ্লিকেশন লিংকসমূহ (Access URLs)

- **Frontend UI:** [http://localhost:3000](http://localhost:3000)
- **Backend API:** [http://localhost:8080](http://localhost:8080)
- **Swagger API Documentation:** [http://localhost:8080/swagger](http://localhost:8080/swagger)

## 🧪 অটোমেটেড টেস্ট চালানোর নিয়ম (Running Tests)

প্রজেক্টে কনকারেন্সি টেস্ট সহ সম্পূর্ণ টেস্ট স্যুট যুক্ত রয়েছে।

যদি আপনার লোকাল মেশিনে .NET 8 SDK থাকে, তবে রুট বা `backend.Tests` ফোল্ডার থেকে নিচের কমান্ডটি চালান:

```bash
dotnet test
```

### কনকারেন্সি টেস্টের উদ্দেশ্য:
- `ConcurrencyTest_MultipleRequests_NeverExceedsTotalSeats`: মাত্র ৫টি আসনবিশিষ্ট একটি ক্লাসে একযোগে ৩০টি রিকোয়েস্ট পাঠিয়ে পরীক্ষা করা হয়।
- টেস্ট নিশ্চিত করে যে ঠিক ৫টি রিকোয়েস্ট `201 Created` পায়, বাকি ২৫টি রিকোয়েস্ট `409 Conflict` পায়, এবং আসন সংখ্যার অতিরিক্ত কোনো সিট বরাদ্দ হয় না।

## 📋 মূল ফিচারসমূহ

1. **কোনো লগইন নেই (Rule 8):** পেইজের উপরে ১৭ ডিজিটের জন্ম নিবন্ধন নম্বর ইনপুট দিলেই সিস্টেম তা শিক্ষার্থীর সেশন হিসেবে ব্যবহার করে।
2. **জিরো ওভার-অ্যালোকেশন (Rule 1 & Bonus 1):** ডাটাবেস লেভেলে Pessimistic Locking (`SELECT ... FOR UPDATE`) ব্যবহার করায় মাল্টি-প্রসেস ব্যাকএন্ডেও রেস কন্ডিশন প্রতিরোধ হয়।
3. **লাইভ কাউন্টডাউন ও এক্সপায়ারি (Rule 9):** সিট হোল্ড করার পর লাইভ টাইমার চলবে। মেয়াদ শেষ হলে পেইজ রিলোড ছাড়াই স্ট্যাটাস `EXPIRED` হয়ে যাবে এবং পেমেন্ট বাটন স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যাবে।
4. **অটোমেটিক সিট রিফ্রেশ (Rule 10):** পেইজ রিলোড ছাড়া প্রতি কয়েক সেকেন্ড পর পর সিটের সংখ্যা হালনাগাদ হবে।
5. **ডাটা পারসিস্টেন্স (Rules 6 & 11):** 
   - `docker compose down` করার পরও ডাটাবেস ভলিউমে সকল ডাটা সংরক্ষিত থাকে।
   - ব্রাউজার রিফ্রেশ বা বন্ধ করে খুললেও শিক্ষার্থীর আইডি এবং চলমান আবেদন সংরক্ষিত থাকে (`localStorage`)।
6. **ইউজার-ফ্রেন্ডলি এরর হ্যান্ডলিং (Rule 12):** সিট শেষ হয়ে যাওয়া বা মেয়াদ শেষ হওয়ার মতো সকল ক্ষেত্রে ব্যবহারকারীকে পরিষ্কার বাংলা মেসেজ দেখানো হয়।
